# Action for 2-4 · 同屏派对

一个纯 HTML + CSS + JavaScript 写成的同屏派对小游戏合集，参照 ApeSoup 出品的《Action for 2-4 Players》(`com.apesoup.action424`)。零依赖，双击 `index.html` 即可游玩，也可部署到 GitHub Pages。

## 🎮 三个小游戏（同屏 2–4 人）

| 游戏 | 玩法 |
|---|---|
| 🛡️ 坦克对战 | 坦克互射，存活到最后者赢下该局得 1 分，率先 7 分获胜；地图有可破坏砖墙掩护 |
| ⚽ 桌球足球 | 1v1 或 2v2，用球员把球撞进对方球门，率先 5 分获胜 |
| 🏎️ 赛车 | 绕中央岛环形赛道，率先跑完 3 圈获胜 |

主菜单可选 **2 / 3 / 4 人**（足球 3 人时自动按 1v1 处理）。

## 🕹️ 操作（同一键盘）

- **1P**：`WASD` 移动 + `空格`（开炮/动作）
- **2P**：`方向键` 移动 + `回车`
- **3P**：`IJKL` 移动 + `U`
- **4P**：`TFGH` 移动 + `R`
- `Esc`：返回菜单

## 🚀 运行

- 直接双击 `index.html` 用浏览器打开即可。
- 或 `python -m http.server 8000` 后访问 `http://localhost:8000`。

## 🛠 技术栈

HTML5 Canvas · 原生 JavaScript（ES6+）· CSS3
