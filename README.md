# 坦克大战 · Tank Battle

一个纯 HTML + CSS + JavaScript 写成的经典坦克大战游戏，并加入了「双人对战」这类同屏派对玩法。零依赖，双击 `index.html` 即可游玩，也可以部署到 GitHub Pages。

## 🎮 玩法

- **1P**：`WASD` 移动 + `空格` 射击；**2P**：`方向键` 移动 + `Enter` 射击；`P` 暂停
- **单人 / 本地双人 / 联机合作**：消灭所有敌方坦克并保护下方基地（⭐ 鹰标志）
- **1v1 对战**：同屏互射，先到 5 分获胜

## ✨ 特性

- ✅ 修复出生坐标错误（坦克原来会卡在基地 / 顶部，导致无法游玩）
- ✅ 修复敌人计数重复扣减、关卡推进异常的问题
- 四种模式：
  - 🎮 **单人游戏**
  - 👥 **本地双人**（同屏合作，1P/2P 共用一块键盘）
  - ⚔️ **1v1 对战**（同屏互射，抢分制，含道具刷新）
  - 🌐 **联机合作**（WebRTC 点对点，无需服务器）
- 经典风格多套关卡地图，逐关切换
- 可破坏砖墙、钢墙、水面、树林掩护（坦克可藏身其中）
- 4 种敌人：普通 / 快速 / 强化（快速子弹）/ 重甲（3 点血），分值不同
- 6 种道具：
  - ⭐ 火力升级（1→2→3 星，3 星可双发并击穿钢墙）
  - 💣 炸弹（清屏；对战中直接击毁对方）
  - 🛡️ 头盔（短时无敌）
  - ❤️ 生命 +1
  - ⏱️ 定时器（冻结敌人）
  - 🧱 铁锹（基地周围砖墙临时变钢墙）
- 出生保护、粒子爆炸、关卡横幅、暂停、音效
- 触屏方向键（手机 / 平板）

## 🌐 联机模式说明

- 「**创建联机房间**」会生成一个**房间码**，把它发给好友
- 好友在同一页面点「**加入房间**」，输入房间码即可连接
- 房主（1P，黄色）运行权威模拟，房客（2P，绿色）发送按键输入、渲染房主下发的状态；两位玩家各自用自己设备的 WASD + 空格操作
- 联机使用 PeerJS 公共信令服务器 + STUN 打洞，公网点对点传输（若双方处于对称 NAT 等无法打洞的网络，会自动尝试公共 TURN 中继）
- 单人 / 本地双人 / 对战模式均无需网络，完全本地运行

## 🚀 运行

方式一：直接双击 `index.html` 用浏览器打开（联机功能需要联网）。

方式二：使用任意静态服务器，例如：

```bash
# Python
python -m http.server 8000
# 然后访问 http://localhost:8000
```

> 提示：联机建议通过 `http://`（或部署到 GitHub Pages 的 `https://`）访问，直接 `file://` 打开在个别浏览器下可能限制 WebRTC。

## 🛠 技术栈

- HTML5 Canvas

- CSS3
- [PeerJS](https://peerjs.com/)（WebRTC 点对点数据通道）
