# 派对竞技场 · Party Arena

一个纯 HTML + CSS + JavaScript 写成的同屏 / 联机派对小游戏合集。零依赖（除联机用 PeerJS CDN），双击 `index.html` 即可游玩，也可部署到 GitHub Pages。

## 🎮 四个小游戏

| 游戏 | 玩法 |
|---|---|
| 🛡️ 坦克对战 | 8 向顺滑移动，炮口平滑转向，带后坐力与震屏；存活到最后得 1 分，率先 7 分获胜；多种地形 + 掉落道具 |
| ⚽ 桌球足球 | 1v1 或 2v2，把球撞进对方球门，率先 5 分获胜；场地中央有反弹柱 |
| 🏎️ 赛车 | 环形赛道，率先跑完 3 圈获胜；含加速带与轮胎障碍 |
| 🎮 横版闯关 | 全新合作平台跳跃：奔跑、跳跃、挥砍，击退敌人、收集金币、越过尖刺与深坑，抵达终点旗 |
| 🏆 竞技赛 | 依次挑战 坦克 → 足球 → 赛车，按名次累计积分，最终决出总冠军 |

## ✨ 手感与机制

- **手感升级**：坦克 8 向移动 + 惯性加速 + 平滑转向 + 开炮后坐力；命中砖墙/击毁坦克有粒子爆炸、屏幕震动与「打击停顿」。
- **机器人**：坦克对战可开启「🤖 机器人」自动补齐到 4 人，机器人会追踪、绕墙、开炮。
- **坦克地形**：砖墙（可毁）、钢墙（可毁弹道反弹）、水面（挡车不挡弹）、草丛（可藏身）、冰面（打滑）；击毁砖墙有概率掉落 🛡 护盾 / ⚡ 连发 / 💨 加速。
- **闯关**：重力 + 跳跃缓冲 + 土狼时间，踩踏或挥砍击败敌人，共 3 条命。
- **趣味玩法**：坦克每局随机触发 ⚡ 高速 / 🔫 连发 / 🪞 无限反弹 模式，HUD 显示局数与「最后一局」提示。

## 🕹️ 模式与操作

- **同屏 2–4 人**：`1P` WASD+空格 · `2P` 方向键+回车 · `3P` IJKL+U · `4P` TFGH+R · `Esc` 返回。
- **联机 2–4 人**：主机「创建房间」得到 **5 位短房间码**，好友「加入房间」即可；掉线自动重连、可凭码中途加入（基于 PeerJS WebRTC，无需服务器）。

## 🚀 运行

- 直接双击 `index.html`。
- 或 `python -m http.server 8000` 后访问 `http://localhost:8000`（联机建议用 http/https）。
