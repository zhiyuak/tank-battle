# 派对竞技场 · Party Arena

一个纯 HTML + CSS + JavaScript 写成的同屏 / 联机派对小游戏合集。零依赖，双击 `index.html` 即可游玩，也可部署到 GitHub Pages。

## 🎮 三个小游戏

| 游戏 | 玩法 |
|---|---|
| 🛡️ 坦克对战 | 坦克互射，存活到最后赢下该局得 1 分，率先 7 分获胜；多种地形 + 掉落道具 |
| ⚽ 桌球足球 | 1v1 或 2v2，把球撞进对方球门，率先 5 分获胜；场地中央有反弹柱 |
| 🏎️ 赛车 | 环形赛道，率先跑完 3 圈获胜；含加速带与轮胎障碍 |

## ✨ 地形与机制

- **坦克**：砖墙（可毁）、钢墙（不可毁）、水面（挡车不挡弹）、草丛（可藏身）、冰面（打滑）；击毁砖墙有概率掉落道具——🛡 护盾 / ⚡ 连发 / 💨 加速。
- **赛车**：上下两条加速带、四个轮胎障碍。
- **足球**：场地中央反弹柱。

## 🕹️ 模式与操作

- **同屏 2–4 人**：`1P` WASD+空格 · `2P` 方向键+回车 · `3P` IJKL+U · `4P` TFGH+R · `Esc` 返回。
- **联机 2 人**：主机「创建房间」得到房间码，好友「加入房间」输入即可（基于 PeerJS WebRTC，无需服务器）。

## 🚀 运行

- 直接双击 `index.html`。
- 或 `python -m http.server 8000` 后访问 `http://localhost:8000`（联机建议用 http/https）。

## 🛠 技术栈

HTML5 Canvas · 原生 JavaScript（ES6+）· CSS3 · [PeerJS](https://peerjs.com/)
